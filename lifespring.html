01 / ENTERPRISE NETWORK SECURITY

LifeSpring Outreach.

Led a four-person team in designing, configuring, and securing a simulated multi-site enterprise network for LifeSpring Outreach, connecting a headquarters in Sydney, Australia, with a regional office in Manila, Philippines. The project involved developing a network architecture that supported secure communication between locations, centralized enterprise services, remote access, and network security monitoring.

ROLETeam Lead & Network/Security Engineer
TEAM4 members
PERIODSummer 2026

The challenge

The assignment was to connect two offices while separating internal networks, protecting services, and supporting remote access. We had to make routing, firewall rules, VPNs, and server services work together.

My role

As team lead, I delegated technical responsibilities, coordinated implementation across the different network components, and assisted teammates with configuration and troubleshooting. I also contributed directly to the technical build and helped lead the team’s final capstone presentation to NCRC and TRMC senior leadership.

Technical architecture

The infrastructure incorporated Cisco routers and switches, OSPF dynamic routing, VLAN segmentation, and pfSense firewalls to establish connectivity and enforce security boundaries between network segments. IPSec site-to-site VPN tunnels provided encrypted communication between offices, while remote-access VPN functionality supported external users. Firewall policies, NAT, and DMZ segmentation were used to control traffic between internal networks, externally accessible services, and remote connections.

The server infrastructure included Windows and Linux systems supporting Active Directory, DNS, DHCP, database services, file sharing, web applications, and centralized logging and security monitoring. These components were integrated into the network architecture to support authentication, service availability, administrative management, and visibility into security events.

Network Architecture & Routing

Designed a two-site topology incorporating Cisco routing and switching, OSPF, VLAN segmentation, and interconnected internal network segments.

Firewalls & Secure Connectivity

Worked with pfSense firewall policies, NAT, DMZ segmentation, IPSec site-to-site VPN connectivity, and remote-access VPN infrastructure.

Enterprise Services

Integrated Windows and Linux server environments supporting Active Directory, DNS, DHCP, file services, databases, and application hosting.

Security Monitoring

Incorporated centralized logging, SIEM monitoring, and file integrity monitoring into the enterprise security architecture.

Leadership & Integration

Led a four-person team, delegated responsibilities, provided troubleshooting support, and coordinated the integration of networking, security, and server infrastructure.

What I learned

The biggest challenge was getting all the separate pieces to work together. It pushed me to troubleshoot across devices and services while making sure my teammates had what they needed.
