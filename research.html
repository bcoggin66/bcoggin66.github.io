Research

Analyzing Build Systems

Undergraduate Research Assistant · University of Central Florida
OCT 2025 — PRESENT

Contributing to an undergraduate research project focused on evaluating the security and reproducibility of open-source software build systems. The research examines how projects using Autotools, Make, and CMake implement compiler hardening techniques, configure build environments, and adopt secure development practices across large software ecosystems.

Developed Bash automation scripts to collect, process, and analyze build-system metadata from hundreds of open-source repositories. This work supports the identification of security-related compiler flags, missing hardening configurations, and differences in build practices across projects. By automating repository analysis, the research enables more consistent evaluation of software build configurations at scale.

The project contributes to broader research in software supply chain security, reproducible builds, and secure software development, with an emphasis on understanding how build-system decisions influence the security and reliability of open-source software.

Build System Analysis

Examining Autotools, Make, and CMake configurations to understand security-related build practices across open-source projects.

Bash Automation

Developing Linux shell scripts to automate repository metadata collection, processing, and analysis across hundreds of repositories.

Compiler Hardening

Investigating security-related compiler and linker flags, including the adoption or absence of build hardening configurations.

Software Supply Chain Security

Supporting research into secure build processes, reproducibility, and potential weaknesses introduced through build-system configuration.

Large-Scale Data Analysis

Organizing and evaluating repository metadata to identify patterns and differences in build practices across software projects.
