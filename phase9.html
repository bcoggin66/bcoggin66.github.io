03 / C PROGRAMMING · INDEPENDENT PROJECT

Phase 9 Card Game.

I built a multiplayer card game entirely in C that runs in the terminal. It was a solo project, with turn-based play, nine phases, and a leaderboard saved between games.

ROLESolo developer
PERIODFeb – May 2025
PLATFORMCommand line

Overview

Built a playable command-line card game from scratch, focusing on game-state management, player interaction, and maintainable C program structure.

Key features

  • Multiplayer turn-based gameplay.
  • Nine progressive phases with card combinations and advancement rules.
  • Deck shuffling, drawing, discarding, and card management.
  • Leaderboard persistence using file input/output.
  • Command-line interaction and input handling.

Engineering takeaways

This project strengthened my understanding of C, structured program design, data handling, and the process of building a complete interactive program independently.
