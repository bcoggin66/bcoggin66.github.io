02 / HACKATHON · APPLICATION SECURITY

EcoShield SecureRoute.

Developed EcoShield SecureRoute during a 12-hour hackathon as a security-focused navigation platform designed to help electric vehicle drivers evaluate potential cybersecurity risks at public charging stations. The application combines charging station information with firmware vulnerability intelligence to provide users with a clearer understanding of potential security concerns before connecting their vehicles.

ROLEFull-stack & cybersecurity contributor
DURATION12-hour hackathon
FOCUSEV charging security

The problem

EV charging decisions typically prioritize availability and convenience. EcoShield explored how firmware security information and known vulnerabilities could become part of the driver’s decision-making process.

The approach

The platform features an interactive map displaying charging locations and categorized security risk levels, allowing users to explore station-specific information, identify potential vulnerabilities, and access routing functionality through Google Maps. Security assessments incorporate firmware information, publicly documented CVEs, and concepts from EV charging technologies and standards, including EVerest and ISO 15118.

My contributions

I contributed across multiple areas of the application, including frontend development, backend integration, mapping functionality, and cybersecurity analysis. The project brought together cloud services, external APIs, and security research to make technical vulnerability information more accessible and actionable for everyday EV drivers.

Application Development

Contributed to the user interface and backend integrations supporting station information, vulnerability details, and security risk classifications.

Mapping & Navigation

Integrated interactive charging station visualization and Google Maps routing functionality to help drivers locate and evaluate charging options.

Vulnerability Intelligence

Worked with CVE information, firmware security data, and EV charging infrastructure concepts to support security assessments.

Cloud & API Integration

Used Firebase, Google Cloud, and external APIs to connect application components and present charging station information.

Hackathon Collaboration

Collaborated on the design and development of a working prototype within a 12-hour hackathon.

Technical context

The project explored EV charging security concepts related to EVerest and ISO 15118. The hackathon prototype demonstrates a security-aware navigation concept, not a certification of charger safety.
